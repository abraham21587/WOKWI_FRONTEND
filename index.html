❓ Cómo usar PHYSICSCYBERLAB

1. Añadir componentes

Arrastra un componente de la barra lateral izquierda hacia el lienzo, o haz doble clic sobre él para colocarlo en el centro. Usa el buscador 🔍 para encontrarlo por nombre.

2. Conectar cables

Haz clic sobre un pin y luego clic sobre otro pin para crear el cable entre ambos. Cancela con Esc o clic derecho. Elige el color del cable en la barra inferior izquierda, y borra un cable con doble clic sobre él.

3. Seleccionar y editar

Haz clic sobre un componente para seleccionarlo. Con la barra que aparece arriba puedes ⟳ rotar (R), abrir sus ⚙ propiedades (valor, voltaje, color…) o 🗑 eliminarlo (Delete).

4. Código Arduino

El botón { } CÓDIGO abre el editor del sketch (setup() / loop()). Puedes anclarlo, dejarlo flotante o minimizarlo con los botones de su cabecera.

5. Simular

Pulsa ▶ INICIAR SIMULACIÓN para correr el circuito en tiempo real y ⏹ DETENER para pararlo. El simulador calcula voltajes y corrientes reales: ¡un cortocircuito o una conexión mal hecha puede "quemar" un componente!

6. Guardar y cargar proyectos

💾 GUARDAR PROYECTO guarda el circuito en tu cuenta; usa el selector 📂 Cargar circuito… para abrir uno guardado y 🗑 para eliminarlo.

7. Descargar tu trabajo

El botón ⬇ DESCARGAR ofrece varias formas de exportar el proyecto actual:

  • 📄 Informe en PDF — resumen listo para entregar: componentes, conexiones y código.
  • 🧩 Código (.ino) — solo el sketch de Arduino, para abrirlo en el IDE.
  • 🗂 Proyecto (.json) — todos los datos del circuito, por si quieres respaldarlo o compartirlo.
